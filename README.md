Tienda Web - Sabores del Sur

Este proyecto consiste en el desarrollo de una aplicación web tipo tienda virtual, enfocada en la gestión de productos, usuarios y pedidos. Fue desarrollado como parte del proceso de formación en Análisis y Desarrollo de Software.

---

Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- PHP
- MySQL

---

Funcionalidades principales

- Registro de usuarios
- Inicio de sesión
- Visualización de productos
- Carrito de compras
- Gestión de pedidos
- Conexión con base de datos

---

Estado del proyecto

Este proyecto se encuentra en desarrollo. Actualmente cuenta con funcionalidades principales implementadas, pero aún se están realizando mejoras en diseño, seguridad y optimización.

---

Mejoras futuras

- Implementación de pagos en línea
- Panel de administración
- Mejoras en la seguridad del sistema
- Validaciones más robustas
- Optimización del diseño responsivo
- Integración con APIs externas
